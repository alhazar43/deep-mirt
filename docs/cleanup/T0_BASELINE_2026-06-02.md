## T0 Decision

The current public invocation style still requires one of:

- `PYTHONPATH=.` when commands are run from `ma-irt/`.
- `PYTHONPATH=ma-irt` when commands are run from the repository root.

For now this requirement is documented rather than changed. The import
ergonomics fix belongs to a later tier because it touches executable code and
must be covered by modular tests.
