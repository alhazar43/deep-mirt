# Format unification: one family, one law, three granularities (2026-08-10)

Author prompt: "GPCM and NRM and 2PL read as 3 disjoint models; string
them into a consistent storyline." The v1 taxonomy sentence (nested
family) was true but inert; the unification has to happen at the level
of the question and the readout, not the algebra. This note is the
worked framing, grounded in the v2 audit and tonight's E6.

## The frame

The three decoders are one divide-by-total likelihood (Bock's nominal
model general; GPCM = slopes constrained to a single discrimination
times the category index; 2PL = that model at K=2). Established
taxonomy, one methods paragraph, no new vocabulary.

The results-level string: the decoders are three DOSES of one
experimental variable -- how much slope structure per item the readout
path must carry (slope dimension 1, 1, K; location structure 1, K-1
ordered, K intercepts). The audited law is tested once per rung:

| rung | what is added | law's prediction | verdict (artifacts) |
|---|---|---|---|
| 2PL | minimal slope/location split | location survives pooling, slope corrupted, key repairs, audit flags | .998/-.975 location; .55 -> .90 slope; discrepancy flags (tab:mass, realstudy) |
| GPCM | ordered thresholds (location gains structure) | added structure behaves like location: robust, design-invariant | E6: raw threshold order tracks classical at rho .98, both arms; slope still .44 -> .90 |
| NRM | per-option slopes (slope family becomes a vector) | fragility follows the slopes; intercepts stay robust; repair goes to the slope vector | keyed contrast story; intercepts .82-.83 across readings; popular-option .653 = the location-only predictor |

Storyline sentence: the shared readout path is a location-preserving,
slope-corrupting channel at every level of category structure; the
separated key repairs exactly the slope family at every level; the
truth-free audit detects the corruption at every level.

Datasets stop being glued: each rung runs on data that possesses the
structure that rung adds, against the strongest external anchor
available there (binary logs vs MML; designed assessment vs classical
calibration; options-logged platform vs distractor point-biserials).
The E9 battery gives the cross-format closure: identical violations
through 2PL and GPCM cells, format as a table column.

## Caveats that belong inside the frame

   is where the prediction-is-not-measurement axis sentence works.
